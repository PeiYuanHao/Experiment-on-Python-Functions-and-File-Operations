## 一、实验名称

**Python 函数与文件操作**

## 二、实验目的

熟悉 Python 的输入输出、随机数的运用、函数的基本运用，掌握函数及 Python 对文件的操作，以及两种文件打开方式的区别，重点熟悉列表及字符串的各种操作。

## 三、问题描述

### 1. 函数与文件

#### 题目 1：随机生成字符并写入文件

使用 `random` 模块中的 `randint()` 方法生成 `1` 至 `122` 之间的随机数，以产生字符对应的 ASCII 码。

将满足以下条件的字符逐一写入文本文件 `test.txt` 中，当写入字符数达到 `1000` 时停止写入：

- 大写字母
- 小写字母
- 数字
- 特殊符号：`'\n'`、`'\r'`、`'*'`、`'&'`、`'^'`、`'$'`

#### 题目 2：统计字符频率和百分比

利用两种方法编写函数，统计 `test.txt` 文件中以下三类字符的频率及百分比：

- 大写字母
- 小写字母
- 数字

要求使用函数实现统计功能。

#### 题目 3：文件内容大小写转换

完成统计功能后，将 `test.txt` 文件中所有小写字母转换为大写字母，然后保存至文件 `test_copy.txt` 中。

### 2. 水仙花数

创建一个判断函数，接受一个正整数参数 `n`，其中 `n >= 100`，判断该数是否为水仙花数。

水仙花数的定义：

如果一个数是 `m` 位数，并且它每个位上的数字的 `m` 次幂之和等于它本身，则这个数是水仙花数。

示例：

```text
1^3 + 5^3 + 3^3 = 153
1^4 + 6^4 + 3^4 + 4^4 = 1634
```

判断函数应返回：

- `True`：表示该数是水仙花数；
- `False`：表示该数不是水仙花数。

请编写一个程序，接受一个参数 `max`，其中 `max >= 1000`，调用上面编写的判断函数，求出 `100` 到 `max` 之间的所有水仙花数。

### 3. TV 选秀

一个选手参加一个 TV 秀，有三扇门，其中一扇门后有奖品，这扇门只有主持人知道。

流程如下：

1. 选手先随机选择一扇门，但不打开；
2. 主持人看到选手选择后，会打开其余两扇门中没有奖品的一扇门；
3. 主持人询问选手是否要改变一开始的选择；
4. 通过编程模拟，证明是否应该改变选择。

请设计一个程序完成上述要求。

## 八、注意事项

1. 所有功能性代码都应封装为函数。
2. 文件读写时应注意文件名是否正确，例如 `test.txt` 和 `test_copy.txt`。
3. 统计字符百分比时，应避免除数为 `0` 的情况。
4. 水仙花数判断函数应只负责判断，不建议在函数内部直接输出结果。
5. TV 选秀题应通过大量模拟实验说明概率差异，一般模拟次数越多，结果越接近理论概率。
